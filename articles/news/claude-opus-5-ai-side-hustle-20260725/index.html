Claude Opus 5 发布，性能追平Fable 5价格只要一半，普通人怎么用它搞副业

昨天 Anthropic 发了 Claude Opus 5。我刷到消息的时候正好在改一个项目的代码，看到 benchmark 数据直接愣住了。

但最让我在意的不是这些分数，而是官方那句声明，性能接近 Fable 5，价格只要一半。

这话的潜台词挺有意思的，上个月 Fable 5 刚发的时候大家还在感叹顶级模型有多贵，一个月后 Opus 5 就把 Fable 级的智能降到了普通人用得起的价位。

这个节奏才是对想做 AI 副业的普通人最有用的。

坦率的讲，模型能力强不强跟你能不能赚钱是两码事。但当一个模型的性价比出现这种级别的跃迁，服务的利润空间直接就被放大了。

顺着这个思路，我梳理了三个方向，从最简单的到最炸的，逐一聊。

方向一，用 Opus 5 做高价值编码服务。

这次 Opus 5 在编码上的提升太夸张了。Frontier-Bench 分数是 Opus 4.8 的两倍多，到了 Fable 5 的 99.5%。CoderBench 3.2 上同样接近 Fable 5 的最高分。

以前你给客户写个自动化脚本或者搭个简单的 SaaS MVP，可能要反复调试好几轮，有些复杂的逻辑甚至模型根本搞不定。现在 Opus 5 一次就能把复杂的编码任务跑通。

我自己之前用 Claude Code 接过企业内部工具的单子，Opus 4.8 断断续续调了两天。换成 Opus 5 的话，半天就够。

效率翻倍，成本不变，你的时薪直接翻倍。这不就是做服务的人最想看到的吗。

方向二，用 Opus 5 做企业流程自动化。

Zapier AutomationBench 的数据我最看重。它测的是模型能不能从头到尾完成一个完整的商业任务，不是单步骤的玩具 Demo。

Opus 5 的通过率是第二名模型的 1.5 倍。以前那些需要复杂配置、多工具联动的任务，现在模型自己能搞定了。

帮小企业搭自动化流程，从客户跟进到财务对账，我以前写过案例，但那时候能做的还比较简单。现在有了 Opus 5，接那些真正值钱的活吧。

价格还降了。同样的成本你能跑出更高的质量，利润率自然就上去了。

方向三，最炸的，桌面自动化服务。

OSWorld 2.0 这个测试最能体现模型的计算机使用能力。Opus 5 在 Fable 5 三分之一的价格下就超越了 Fable 5 的最好成绩。你没看错，三分之一的价格，更好的表现。

那结果会怎样呢，不对，这事情想说清楚了得换个说法。

你想想看，以前给客户做桌面操作自动化，比如批量处理表格、自动填写几百份表单、从老系统里迁移数据，这些活用 Fable 5 当然也能做，但 API 账单高得吓人，你报出去的价客户不一定接得住。

现在 Opus 5 把成本压到了三分之一。以前报价 5000 的单子，成本只要几百块。那些算不过来账放弃的需求，重新算一遍都能跑了。

每次模型能力的跃迁，都是在给做服务的人放大利润空间。用好工具帮别人解决问题，中间差价就是你的利润。

Opus 5 把 Fable 级的智能降到了 Opus 4.8 的价格。窗口期就在这几个月，早点动手把客户圈住，后面的人就难抢你的饭碗。

大时代啊，朋友们。

常见问题

Claude Opus 5 比 Opus 4.8 强在哪里

Opus 5 在编码和知识工作上提升巨大。Frontier-Bench 得分是 Opus 4.8 的两倍多，ARC-AGI 3 得分是第二名模型的三倍。在计算机使用基准 OSWorld 2.0 上，它以 Fable 5 三分之一的价格超越了 Fable 5。在生物科学评测的各个维度上都有明显提升，有机化学任务比 Opus 4.8 高了 10.2 个百分点。

普通人怎么用 Claude Opus 5 做 AI 副业赚钱

三个方向最直接。一是接编码服务，帮小企业写自动化脚本或搭系统，Opus 5 的编码效率翻倍能让你时薪翻倍。二是做企业流程自动化，客户跟进、财务对账等复杂工作流现在 Opus 5 能搞定。三是桌面自动化服务，批量处理数据、自动填表这些以前成本高的活现在直接利润翻了三倍。关键在早点跑通流程，把客户圈住。

Claude Opus 5 的 API 价格是多少

Opus 5 的定价和 Opus 4.8 保持一致，价格没涨但性能大幅提升。官方同时提供了 effort setting 功能，你可以根据任务复杂度调整模型的推理深度，简单任务用低 effort 模式省 token，复杂任务开高 effort 模式拿质量，同一个模型两头都能吃，比之前灵活很多。
