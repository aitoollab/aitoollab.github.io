AI做3D网站怎么接单赚钱，三天426星的开源技能包dream-loop实操拆解

AiToollab，专注普通人能看懂、能动手的AI副业和自动化实战。

故事是这样的。前天早上我们的Scout在扫GitHub新仓库，捞出来一个只有101星的东西，叫dream-loop，仓库是当天凌晨才建的。我当时扫了一眼描述，一个让agent做炫目3D视觉的技能包，没太当回事。

今天早上再查，426星，54个fork，三天走完的。

它干的事一句话能讲完，但越想越有意思。你让AI做一个3D网页或者游戏场景，以前它交出来的是什么东西大家都见过，灰模、乱码贴图、跟PPT一样的静态排版的「动画」。dream-loop的解法是给AI套了一个闭环，先让AI用图像生成自己dream一张高质量的目标画面，然后照着这张图去写代码搭场景，搭完截图，交给一个独立的critic子代理对比目标图和实机画面，挑刺，改，循环，直到critic点头。满意了还能回到第一步，基于当前成果再dream一张更好的，继续迭代。

坦率的讲整个流程就是，AI自己当甲方，AI自己当乙方，再安排一个AI当监理，三方在你睡觉的时候互相卷。

让我真正坐起来的是时间点？？？GPT-6 Astra是第一批把3D能力放到台面上的模型，外网这几天全是在Blender里让AI一晚上重建一栋房子的视频，Reddit的aigamedev板块有帖子标题直接写的，不用再学Blender了= = 工具刚出现，行情还停在原地，这种错位就是信息差。今天把这条线整个捋一遍。

先看清行情，会动的页面到底值多少钱

聊工具之前老规矩，先把钱的事说清楚，因为工具的价值完全取决于行情。

海外这边有个2026年的动效网站成本指南，数据来自Fiverr、Upwork和Clutch.co的公开报价。纯CSS特效和轻量动画，freelancer报价300到1000美元一个项目；用GSAP做滚动叙事和交互的，1500到4000美元；React或Vue框架级的动效网站，3000到8000美元；再往上，那种能上Awwwards首页的沉浸式WebGL体验，机构报价直接3000到30000美元。个人freelancer的时薪档位是15到40美元，机构是40到120美元。

国内行情按秒计价。搜狐今年7月那份3D动画价格指南写得很直白，基础档150到300元一秒，就是预设模型库加简单几何体那种；中等复杂度800到1500元一秒；专业公司全流程服务1500到3000元一秒。一个30秒的片子，低档4500到9000元，高档能到9万。企业宣传片、产品演示、工业流程动画，全是这个盘子。

你品品这个价格结构。客户付的每一分钱里，大头是「把它做出来」的执行成本，建模、K帧、调曲线、渲染，纯手艺人肉堆出来的。创意和沟通的部分其实占比不高。

而「做出来」，恰恰是AI这两年吃掉最快的环节。

那为什么价格还没崩？因为大部分甲方根本不知道AI已经能干这活了，市面上的服务还是按人天的逻辑在报价。这就是窗口。

这个426星的技能包到底卷在哪

回到dream-loop本身。它跟「让AI直接写个3D网页」的区别，是流程上的代差。

你直接跟AI说给我做个炫酷的产品展示页，它大概率还你一张灰扑扑的PPT。原因不复杂，模型没有「目标」，它不知道「好」长什么样，只能凭训练语料的平均值往下糊。dream-loop补的就是这一块，先dream一张目标图，把「好」具象化成一张可以被对比的参照物，后面的每一轮迭代都有明确的及格线。

README里那个官方示例我看了好几遍。prompt大意是，做一个体素风格等距视角的暗黑奇幻场景，湿滑反光的地板，Elden Ring那个味儿，Three.js浏览器里跑，60帧以上，不许下载现成资产，限时一小时，点击移动、拖拽转镜头、滚轮缩放，世界要有生命感。GPT-6 Astra在Codex里high档跑出来的结果，是一个真能玩的、光影氛围直接到位的demo，在线版挂在dream-loop-demo.anshu.dev，谁都能点进去看。

一小时，从零，不下载资产。这个活儿放在上面那个报价单里，是3000美元往上的一档。

装起来也是两行的事，npx skills add achimala/dream-loop，或者直接丢进Claude Code的skills目录。但它有几个硬前提你得知道，你的agent得有图像生成能力（Codex、Grok内置的，或者喂个Gemini API key），得有视觉输入，最好支持子代理。要自定义3D建模还得装Blender，作者建议走Blender的MCP或脚本接口而不是computer use，效果好得多。目前只在GPT-6 Astra上测过，作者原话是Claude Fable 5.1这种级别的「大概率也行」，= = 也就是说他自己还没验证完，这是个上线三天的仓库的正常状态。

顺着这条线往浏览器方向看一眼，还有个上周同期上线的叫bang-motion，116星，专做动效包装，产品片头、频道intro、动态排版，输出是单个index.html，双击就播。它的核心卖点是一堆「反PPT规则」，不许场景靠淡入淡出切换、必须有运镜、每秒必须有东西在动。这俩凑一起你会发现，3D场景和动效包装这两个外包大头，已经各有一个开源技能包在改了。

这个机会普通人怎么吃，三刀

行情有了，工具有了，怎么变成钱？还是按门槛从低到高切。

第一刀，直接接单做页面。目标客户特别具体，卖高客单价实物的小品牌，潮玩、香氛、精酿、家具，他们的产品天然适合转着圈展示，但找机构做沉浸式落地页报价四位数美元起步，预算对不上。这就是个人接单的空间，用dream-loop加Codex出一版demo，拿着demo去谈，报价按国内市场的一半打，3000到8000人民币一单，你的执行成本是一个下午加一点API费。获客路径也现成，小红书搜3D官网、WebGL，一堆设计师在发案例接私单，你发的作品比他们快十倍；海外路径是把自己的demo挂上Awwwards，那个网站本身就是甲方橱窗，上面那些studio的报价页我看过，全是私信转化来的。

第二刀，给同行提效，赚改稿的钱。说实话这个可能更快见钱。现在大量动效设计师和小型studio的处境很尴尬，客户要「再炫一点」，但人力加不动。你去谈的不是替他做，是做他流程里那个「dream目标图」的环节，客户提完需求，你一晚上出三张不同风格的「成品预览图」让客户选，选定了再进生产。甲方最痛的不是贵，是不知道成品长什么样，你这一步直接把确认周期从两周压到两天。按预览收费，一单500到1500，谈下来的都是长期单。你想想看，这活儿其实就是在卖AI的dream能力，成本几乎为零，定价却按咨询费走。

第三刀，往部署服务层走，帮人把这套系统跑起来。这个逻辑跟我昨天写screenwriting-skills那篇讲的第三刀一模一样，插件装得上和用得起来中间隔着一条鸿沟。得有Codex或者Claude Code的环境和订阅，会配图像生成的key，装Blender、配MCP，还得看得懂critic循环为什么卡住。这个断层就是生意。远程部署加一场两小时的培训，打包500到1500，客户画像精确得很，独立设计师、想接AI单但没跑通工作流的接单工作室、被甲方「要3D感」逼到连夜学Blender的平面设计爱好者。这批人付费意愿强，因为他们每接一单都能把部署费赚回来。

三刀看下来共同点很清楚，工具把执行成本砸穿了，但没有砸穿「知道要什么」和「让别人相信你能做到」这两件事。前者靠dream闭环帮客户解决，后者靠你先动手别人还在观望的时间差。

几个坑，看清楚再动手

第一个坑，模型依赖。技能包目前只在GPT-6 Astra high档上验证过，弱一档的模型大概率critic循环半天收敛不了，token费烧得你肉疼。开工前先拿一个小场景试跑一轮，确认你的模型组合能出活再报价，别拿客户的deadline练手。

第二个坑，性能陷阱。浏览器里跑WebGL，手机上是另一回事。demo在M1芯片上60帧不代表客户老板的破安卓机能跑。交付前必须真机测试，尤其是滚动驱动的场景，这项检查写进你的交付清单，不然尾款收不回来。

第三个坑，交付边界。AI很擅长把场景做得「第一秒很惊艳」，不擅长让你点进去之后的三十秒依然有内容。接单合同里把时长、交互点数量、修改轮次白纸黑字写死，两轮封顶，超过就加钱。这个行当老话了，改稿改到破产的从来不是技术不行，是需求没锁死。

还有一个资产坑反而是机会。dream-loop明令不许下载现成资产，全部从零生成，这帮你避开了素材版权的雷，但你交付的每个模型也因此都是独一份的。报价的时候把这个当卖点讲，「100%原创资产」那几个字，甲方爱听。

如果你看到这里觉得能做

我的建议这个周末干三件事。第一，把Codex或者Claude Code的环境理清楚，五分钟装好dream-loop，拿你自己的产品，手办、茶叶罐、你家电饭煲都行，跑一版360度展示页，感受一下一小时的成品和上面报价单里那一档的差距。第二，去小红书和Upwork各搜十个「3D落地页」的真实需求帖，把客户原话抄下来，那就是需求表。第三，挑其中最好说话的一个，拿着你的demo私信过去，第一单哪怕收1500，你要的是作品集和一句真实客户评价。

以前入这行的门票是三年Blender加一整部GSAP文档。现在门票是一个npx命令，和一个愿意在周日晚上动手的你。

窗口期这个词都说滥了，但三天的仓库和还没反应过来的报价单摆在一起，你懂的。

常见问题

3D网站制作多少钱一个

海外公开行情，freelancer做动效网站每小时15到40美元，单个项目300到2000美元，涉及WebGL交互的偏上限，机构报价3000到30000美元。国内3D动画按秒计价，基础档150到300元一秒，专业公司全流程1500到3000元一秒。用AI工作流个人接单，3000到8000人民币一单是有行情支撑的定价区间。

dream-loop是什么

一个开源agent技能包，2026年9月7号上线，三天426星。核心是个闭环，AI先用图像生成dream出一张高质量目标画面，照着目标写代码搭建，再由独立的critic子代理对比实机截图给反馈，循环迭代直到满意，然后还能升级目标继续迭代。

不会Blender不会Three.js能接这种单吗

纯手工时代不行，现在执行层门槛被大幅压低，但不是躺赚。工具解决的是「做出来」，你的agent得有图像生成和视觉能力、模型要够强、跑出来的东西你得会判断。审美、需求沟通、报价谈判仍然是人干的活，这部分恰恰是行情的价值大头。

做3D网站接单去哪里找客户

国内看外包平台的产品展示和官网定制类目，小红书搜3D官网、沉浸式落地页，大量真实需求在设计师私信里。海外看Upwork和Fiverr的WebGL、three.js类目，把自己的demo挂上Awwwards，它本身就是甲方橱窗。

AI生成的3D场景版权有问题吗

注意三层，AI生成资产的商用授权各法域要求不同，交付前自己复核。dream-loop禁止下载第三方资产、全部从零生成，反而降低了侵权风险，可以把100%原创资产当卖点。最后看清楚GPT-6、Claude这些模型订阅条款里的商用范围。
