它是个什么东西呢。一个Claude Code的编剧技能包，13个技能，作者把19本编剧书，悉德·菲尔德的《电影剧本写作基础》、麦基的《故事》和《对白》、《救猫咪》、埃格里的《编剧的艺术》，中美日三个国家的，全部蒸馏成了可以调用的工作流。甚至还塞了两套完整语料进去，契诃夫七个长篇剧本加独幕剧，小津安二郎的六部剧本集。

我点开README看的时候脑子里第一个画面就是，这不就是把一个编剧系四年的书单，压缩成了一个下午吗？？？真的，我盯着那个19本书的书单看了好久，每一本我都买来翻过，加起来小两千块钱，还没读完。

但让我真的坐起来的不是星数，是我顺着它去查了一下短剧剧本的收稿行情。一部80到100集、5万字左右的短剧剧本，行业公开的保底价是1万到2万人民币起步，过了稿还有千分之三到千分之七的分成。海外收稿，2万起。

写剧本这件事，曾经是纯手艺活，靠的是师傅带徒弟、大量读书、反复被毙。现在有人把「大量读书」这一步开源了，上线才第三天，还热着，知道的人不多。今天就把这条线整个捋一遍。

先看清行情，剧本到底值多少钱

聊工具之前，先把钱的事说清楚，因为工具的价值完全取决于行情。

短剧这几年的市场规模大家多少有概念，DataEye的数据显示2025年微短剧加漫剧做到了1000亿，2026年预计突破1200亿。盘子大了，对剧本的胃口就大。《每日经济新闻》采访过一位平台剧本编辑，她说自己邮箱一个月挤进来200个本子，社交平台上天天有编辑在线吆喝「收短剧剧本，保底1.5W起加分成」。

行情拆开看大概是这样的。刚入门的新手编剧，一部保底1万到1.5万；有作品上线过的，1.5万到2万；手里有千万级充值作品的，2万到3万；现象级爆款加持续上榜的头部，5万起步，传说里月入10万的那批人，据从业者估计占全行业1%左右。

听着很美好对吧？先别急，还有一半。

那个月收200个本子的编辑还说了另一句话，最后能过一两个就算不错。。。淘汰率98%往上。一位2022年就入局的工作室负责人在接受采访的时候讲过他们的至暗时刻，开年往平台交了10个剧本，全毙。之前闭眼复制的「追妻火葬场」配方，一夜之间失灵。

所以短剧剧本这个生意的真实面目是，单价高、需求大、但通过率极低，死在改稿路上的比死在动笔前的多得多。行业卷到什么程度呢，编辑的原话是，现在平台要求「微创新」，还是那个核心爽点，但要叠加一个小变化，改大了怕两极分化，改小了又是同质化。

记住这个背景。下面这个技能包的价值，恰恰就藏在这个背景里。

这个开源技能包到底干了件什么事

先说清楚它跟直接跟ChatGPT说「帮我写个短剧剧本」的区别，这个区别是本质性的。

你让AI裸写剧本，它吐出来的是「看起来像剧本的文字」。没有结构意识，不知道第几集该卡付费点，人物动机经不起推敲，对白全是正确的废话。编辑扫两页就扔进毙稿箱。

screenwriting-skills做的事情是把专业编剧的工作流搬进了Claude Code。它有一个总编排技能sw-workflow，把整个创作切成阶段，前提，结构，人物，场景，初稿，改稿，投稿，每个阶段告诉你该调用哪个技能、交付物是什么。所有项目状态存在一个story-bible.md里，今天写一半关掉，明天打开接着干，AI记得你人物小传的每一个设定。

再往细了看，每个技能都是真书单撑起来的。sw-story-structure里是悉德·菲尔德的范式、救猫咪的节拍表、麦基的事件-场景-序列-幕、还有陆军《编剧理论与技法》里的起承转合。sw-dialogue里是麦基《对白》的「说出的、未说出的、不可说出的」，配上戏曲唱词的「典雅通俗、动作性、性格化、潜台词」。sw-scene-craft里那句「enter late leave early」，进场要晚退场要早，是全世界编剧课都在教的场景压缩术。

最让我意外的是两个语料技能。chekhov-dramaturgy把契诃夫从《海鸥》到《万尼亚舅舅》的改稿路径做成了工作表，ozu-screenplay-style拆了小津的「嫁女儿结构」，六部剧本共用一副骨架、换不同的血肉。这俩东西你市面上买不到，是作者自己啃完全集蒸馏的。

还有一点对中文写手极其关键，技能正文全是中文的，来源引文用的是焦菊隐、童道明这些译本的中文表述。触发词也做了中英双语，你用中文说「帮我看看这个戏核立不立得住」，它知道该调sw-premise-theme。

装起来也就两行，在Claude Code里执行 /plugin marketplace add jtydhr88/screenwriting-skills，然后 /plugin install screenwriting@screenwriting-skills。完了你的编码助手就是一个读过19本书的编剧助理。

这个机会普通人怎么吃，三刀

行情有了，工具有了，怎么变成钱？我还是按门槛从低到高切三刀。

第一刀，自己写本子投稿。最直接，也是把技能包价值吃满的玩法。但姿势要对，千万别闷头写完5万字再投，那是98%淘汰率里的分母打法。正确流程是，先在小红书、豆瓣稿费银行、编剧征集帖上找收稿编辑，人对题材和风格，拿大纲加人物小传试水，过了再动笔写前10集，短剧的付费卡点就在前10集，编辑点头这10集，签约概率直接翻几倍。技能包在这个链路里每个环节都有活干，sw-premise-theme的五个前提问题帮你毙掉自己立不住的点子，sw-industry-business里连logline怎么写、投稿信怎么发、签约的预付款比例都讲了。你想想看，一个本子按30天写完算，就算头一个月全毙，毙稿过程里你攒下的结构感，是看10本书换不来的。

第二刀，给已经在写的人当「剧本医生」。说实话，这个可能是更快见钱的切口。短剧工作室什么最缺？不是枪手，枪手一晚上能糊20集，缺的是能一眼看出「这个戏核散了」「第三集卡点泄了」的把关人。以前这活是资深编辑干，现在你拿技能包里的五步场景分析、节拍检查表，对着稿子逐集过，出一份结构诊断报告。这个服务在接单市场上没有标准价，我判断一份万字诊断收到500到2000元不过分，因为你替工作室省的是「投产后才发现本子不行」的几十上百万。顺路还能把海外单接了，ReelShort那批出海平台收英文本，AI漫剧出海被业内叫作2026元年，中国底子加海外壳的本地化改写，正是技能包sw-format-adaptation加判断力的组合拳。

第三刀，往工具服务层走，帮人把这套编剧系统搭起来。你以为装个插件很简单？先要有Claude Code的环境和订阅，中文接单场景还得会配触发词、会读那13个技能的文档、会建story-bible。这个断层，跟之前video-ai-talking那篇讲的部署服务是一模一样的逻辑。远程部署加一场两小时的「怎么用技能包改出自己的第一部本子」培训，打包收500到1500。你的客户画像非常具体，网文转短剧的作者、想搞副业的编剧系学生、被毙了十个本子找不到原因的工作室枪手。这批人付费意愿比普通人强得多，因为他们已经在这个行业里，知道钱在哪。

三刀看下来你会发现共同点，这个技能包降低的是「方法论」的门槛，没有降低「判断力」的门槛。它保证你写出来的东西不像外行，但编辑愿不愿意掏钱，还得靠你自己那点对故事的判断。这恰恰是机会所在，工具平权之后的窗口期，赚的正是谁先动身的钱。

几个坑，先看清楚再动手

第一个坑，AI味过稿难。编辑一天看几十个本子，对「正确但空洞」的台词有生理性厌恶。AI初稿一定带着那种四平八稳的塑料感，人物开口就是主题，情绪全靠形容词。用技能包生成的每一稿，必须自己逐场过一遍，把潜台词加进去，把解释性的废话删掉。麦基那本《对白》里说对白是动作，不是信息播报，这句话你得真的信。

第二个坑，版权红线。README里作者写得很清楚，许可是个人学习使用，原书引文版权归原书和译作者所有。你学它蒸馏出来的方法写原创剧本没问题，把reference.md里的译文段落直接搬进交付物，那是给自己埋雷。海外单更要注意，不同市场对AI生成内容的披露要求不一样。

第三个坑，题材陷阱。编辑明确说过科幻类基本不收，制作成本压不住。新手最容易犯的错就是写自己爱看的，而不是市场要的。动笔前花半天去刷一遍红果、抖音短剧的热榜，看看现在活下来的都是什么配方，再决定你的「微创新」创新在哪。这个动作AI替不了你，得自己看。

还有一个心态坑，把「保底1.5万」当预期，把「过稿」当概率事件来管理成本。行业里正常节奏就是写三毙二，李梦那种一年卖30多个本子的工作室也是靠数量喂出来的。给自己定的是「三个月写完整4个本子」的产量目标，不是「第一个必须过」的质量目标，前者可控，后者玄学。

常见问题

短剧剧本多少钱一部

市面80到100集的短剧剧本大约5万字，行业公开行情是新手保底1万到1.5万元，有作品上线的编剧1.5万到2万元，有千万级充值爆款作者的保底能到2万到3万甚至5万。分成一般在千分之三到千分之七，海外收稿从2万元起步。

screenwriting-skills是什么

一个开源的Claude Code编剧技能包，2026年9月6号上线，三天382星。它把19本中美日编剧书加上契诃夫戏剧全集和小津安二郎剧本集，蒸馏成了13个按创作阶段调用的技能，覆盖前提、结构、人物、对白、场景、格式、投稿全流程，技能正文是中文的。

用AI写的剧本平台收吗

平台收稿看成品质量，不看写作工具。但要自己把关两件事，技能包蒸馏的是方法不是原文，别直接搬引文段落；过稿后剧情雷同、侵权这些风险最终由投稿人承担。

完全没写过剧本能用吗

能装能用，但别指望一键出爆款。它把「读过19本书」这一步帮你省了，但前10集卡点设计得好不好、戏核立不立得住，最终还得你自己有判断。建议先拿一个点子走一遍完整工作流，感受一下差距。

短剧剧本通过率怎么样

很低，有编辑说自己月收200个本，过一两个就算不错，同质化淘汰率98%以上。正确打法是先对题材、写大纲和前10集试水，不要闷头写完5万字再投。
