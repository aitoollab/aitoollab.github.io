别一上来接电商系统

Claude可以做什么副业，网上爱吹独立开发。我自己的建议更土，先接活动落地页和报名小程序。需求清楚，验收也清楚。电商、支付、会员积分这些，坑深，改到你崩溃。怎么说呢，你不会写代码没关系，你得会把需求写成一页纸。

用Claude赚钱的总路径，这篇Claude赚钱教程铺过。Cursor那条线，这篇Cursor副业教程更偏建站。今天这篇只讲Claude Code怎么把单子做完。

接单四步，核心是验收

第一步，让客户发三个参考链接，再问必做功能和不做功能。第二步，把这一页需求丢给Claude Code，说，按这份说明生成一个能在手机打开的页面，先做报名表和班次列表，别做支付。第三步，你自己用手机点一遍。第四步，改三次就收尾款，别无限改。

我踩过坑。第一次让它重写整个项目，token烧得飞起，页面还是乱。后来改成一次只动一个文件，稳多了。省token的细节，这篇Claude Code省token教程写过，我自己也还在摸索。

定价就三档，别按小时

活动落地页，800到2000。带表单的报名小程序，3000到8000。按月改版的，另算。我自己第一单收了800，干了两晚，时薪不好看，但有了案例。第二单才敢报到3500。你试试先接一个只要填表的页，别碰支付。

客户能看出来是AI写的吗。看出来也不影响。他把注释和报错清干净，比纠结出处有用。真的，验收过不了，再便宜也是白干。

Claude Code变现常见问题

不会写代码能不能用Claude Code变现？

能，但你得会验收。页面打得开，按钮点得动，手机上看不乱，这三件事过了才能交。

Claude Code接单一单多少钱？

活动落地页800到2000，报名小程序3000到8000。别接无限改，改三次就收尾款。

Claude Code和Cursor哪个更适合接单？

我自己用Claude Code多，长任务稳一点。Cursor上手快。选你会天天打开的那个，别两个都买。

Token烧得太快怎么办？

别让它重写整个项目。一次只改一个文件，需求写进一页说明里。省token那套，我另有一篇专门讲。

客户能看出来是AI写的代码吗？

看出来也不影响，客户关心的是能不能用。你把注释和报错清干净，比纠结出处有用。
