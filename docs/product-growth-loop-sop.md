# AiToollab 产品升级与用户闭环运行手册

更新时间：2026-09-04

## 一、产品路径

1. **免费层**：教程解决一个具体问题；首页二维码进入「人工智能掘金」交流群。群内只承诺真实能提供的资料、问题交流和实操反馈，不承诺收益。
2. **入门层**：AI副业提示词全家桶，¥39。交付的是按场景整理的可复制提示词、说明和示例；买前先看免费预览，购买后按小报童页面规则履约。
3. **进阶层**：暂不售卖。收集用户反复出现的具体需求，达到真实需求量并完成验证后，再上线垂直场景包或小范围执行陪跑。没有验证前不写价格、不写销量、不写效果承诺。
4. **高阶层**：暂不开放。只有在进阶产品稳定交付、有真实案例后，才增加定制服务入口。

## 二、用户闭环 SOP

### 1. 获客 → 激活
- SEO文章先解决问题，结尾统一出现「先拿一个可执行的结果」组件。
- 用户动作顺序：读教程 → 试一个步骤 → 扫码进群交流 → 需要成套工具时查看 ¥39。
- 新群成员欢迎语：`欢迎进「人工智能掘金」。先说你想用AI解决的一个具体问题，我会把相关教程、可复制步骤或避坑信息发给你。这里不承诺躺赚，只讨论怎么把事情做出来。`

### 2. 激活 → 转化
- 第1次接触：先问场景，不先发购买链接。
- 用户明确需要多个场景模板时，再发：`如果你不想每次从空白对话框开始，可以先看这5个免费预览；确认适合你的场景后，再看¥39完整包：/prompt-pack/`
- 每周最多一次产品提醒，先分享一个可执行方法，再给产品链接。

### 3. 购买 → 留存/升级
- 购买后引导用户完成一个最小任务：选一个提示词，填入自己的场景，产出一份结果。
- 收集三项反馈：使用场景、是否产出结果、卡在哪里。
- 只有当同一场景出现重复需求，才考虑做垂直包；先做小范围验证，再决定是否收费。

### 4. 推荐
不做虚假返现或夸大裂变。先邀请已经产出结果的用户自愿分享：`如果这套方法帮你省了时间，欢迎把文章或免费教程转给同样卡在这一步的人。`

### 5. 反馈与迭代
每周整理邮件、群问题和留言，按三类记录：
- 高频卡点：补进免费教程；
- 可复用模板：补进¥39产品；
- 重复且需要指导的任务：进入进阶产品候选池。

## 三、每周检查表

- [ ] 首页二维码可正常展示，群二维码未过期
- [ ] 首页、产品页价格/交付/售后口径一致
- [ ] 新文章底部有闭环组件
- [ ] 不出现未经核验的评分、评价、用户数量、收益数字
- [ ] 统计教程→群入口→产品页点击，不只看页面访问量
- [ ] 记录新增反馈、已处理问题和下一轮改动

## 四、当前真实边界

- 不把“提示词能赚钱”写成结果保证；
- 不用虚构评价替代社会证明；
- 不提前售卖尚未验证的进阶产品；
- 产品页面的交付与售后以小报童当前公示规则为准；
- 真实案例、收入和用户反馈获得后再公开展示，并保留来源与时间。
